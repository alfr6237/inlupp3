## How to use the program
*** 
This java program is a symbolic calculator that parses the user's input and evaluate expressions. 
### How to run the program
*** 
1. Download the repository. 
2. Use the following terminal command to run the program:
```bash
mvn compile exec:java
```
## Running tests
***
Use the following terminal commands to run different tests:
1.  To run test
```bash
mvn test
```
2. To remove compiled files
```bash
mvn clean
```
